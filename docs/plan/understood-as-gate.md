# Understood as

Understood as: delete Gitea from rukie entirely and rebuild it as a new Go forge whose only repository backend is Ruk, with free breaking changes on both sides because neither has shipped. The rebuild is agentic-first: agents act through scoped tokens on human accounts, work as Intents with machine-checkable acceptance contracts, evidence as signed Ruk attestations, queues as saved Views, and assignment as path-covering Leases. Humans supervise through a zero-JavaScript, high-density, Instrument-styled UI. One operation table serves HTML, JSON, Markdown, MCP, and a generated CLI. Every repository mirrors automatically to GitHub, GitLab, and Forgejo with per-mirror mode and ref selection. Built-in CI must outlast and outperform GitHub and GitLab CI: durable leases, fencing, a content-addressed result cache, and podman sandboxes. The plan at local://rukie-ruk-native-forge-plan.md encodes every settled fork; approval of that plan names the exact demolition set and keeps all outward writes behind fresh consent.
