## 3. Cluster gates (run after each cluster lands; every commit builds)

Standard gate set after **every** cluster and each commit within it:

```
cargo fmt --all -- --check
cargo clippy --workspace --all-targets
cargo nextest run --workspace
```

Per-cluster additions:

- **A, B, F, G** (daemon/transport-heavy): also run the daemon socket tests (`cargo nextest run -p ruk`); oracle-backed tests use external `git` as a test-only dependency. After **B**: run the daemon suite twice (flaky check on the new writer task).
- **Method::ALL consistency test (binding for every method-appending row — all 14: `repo.stat, tree, refs.list, compare, search, archive, events.tail, repo.init, repo.delete, repo.rename, repo.fork, remote.refs, claim.renew, policy.set`):** `method_table_is_consistent_and_covers_the_contract` (`ruk-core/src/protocol.rs:5417-5484`) must be updated **in the same commit** as any method-table row — every new `Method` goes into the `required` array (:5431-5479) and the count assertion (:5483, expected **60**; the assertion is the authority).
